# ScaleUp Sidekicks

Marketing site for ScaleUp Sidekicks. Four static pages, no framework.

- `index.html` — home, with the signature pipeline diagram
- `how-it-works.html` — the three-step plan and pricing
- `proof.html` — a real Content Engine run plus capability diagrams
- `book.html` — the 15-minute call booking
- `styles.css`, `script.js` — shared styles and motion
- `demo-assets/` — the sample run artifacts

## Running locally

Any static server works, for example:

```
python3 -m http.server 4173
```

Then open http://localhost:4173.

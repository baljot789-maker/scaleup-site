# Demo assets

Demonstration artifacts for the ScaleUp Sidekicks proof page. Created 2026-07-05 at Joe's direction.

## What these are

A complete Content Engine run on a sample expert interview. The firm, Bellhaven Wealth Advisors, is fictional, and every name and detail in these files is invented. The workflow shown (interview in, compliance-checked assets out) is the real workflow. The proof page presents these as a sample run, never as client work.

## Files

- `interview-transcript-excerpt.txt` — the raw "before." Contains the three compliance problems the site highlights in red: a named client story (04:35), a performance claim (05:04), and universal specific advice (05:57).
- `blog-post-final.md` — the finished "after." Contains the three fixes the site highlights in green: anonymized composite story, process language instead of returns, education framing with an advisor referral.
- `social-series-final.md` — four LinkedIn posts from the same interview.
- `email-sequence-final.md` — three nurture emails from the same interview.
- `dashboard.html` — the pipeline dashboard, embedded in an iframe on proof.html.
- `sample-landing-page.html` — the sample landing page, linked from proof.html.
